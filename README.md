# 合社日历

> 有温度的中国风日历🍵 - Windows 桌面版（Tauri 2）
>
> 网页版可作为样式与功能参考：[在线示例](https://cal.heshe.tech) | [开源地址](https://github.com/scutken/he-calendar)

## 应用介绍

合社日历 Windows 桌面版在保留中国风月历、农历黄历、节气主题的基础上，新增按日待办、系统托盘常驻与到点提醒。

### ✨ 核心特色

- **🪟 Windows 桌面应用**：Tauri 2 打包，托盘常驻，关闭窗口默认回到托盘
- **📝 按日待办**：选中日期增删改待办，格子显示未完成标记
- **🔔 待办提醒**：可设当天提醒时刻，推送 Windows 通知；支持开机自启
- **🎨 24节气智能主题**：根据当前节气自动切换配色
- **📅 农历与黄历**：完整的农历信息、节气、传统节日和黄历宜忌
- **🌈 多样主题风格**：素雅、水墨、朱红、鎏金、黛蓝等
- **🌤️ 天气信息**：输入城市名查看实时天气

### 🚀 开发与打包

前置：Node.js 20+、Rust（rustup）、Windows 上建议安装 Visual Studio Build Tools（C++ 桌面开发）。

```bash
npm install
npm run desktop:dev      # 开发
npm run desktop:build    # 产出 Windows 安装包（NSIS）
```

纯前端预览（无托盘/原生通知；待办降级 localStorage）：

```bash
npm run dev
```

### 💡 操作指南

- **切换月份**：滚轮或左右箭头
- **选择年月**：点击顶部年份/月份
- **回到今天**：点击「今天」
- **待办**：右侧黄历下方添加/完成/删除；可选提醒时刻
- **托盘**：左键显示/隐藏窗口；右键可打开日历、今日待办、切换提醒总开关或退出

## 技术栈

- **Tauri 2**：Windows 桌面壳、托盘、通知
- **Vue 3 + Vite**：前端界面
- **SQLite**（`tauri-plugin-sql`）：待办与设置持久化
- **Day.js / tyme4ts**：日期与农历黄历
- **Lucide Vue Next**：图标
- **小米天气 API**：天气数据
